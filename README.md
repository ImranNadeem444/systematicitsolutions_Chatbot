# AI Chatbot for Systematic IT Solutions

## Overview

An AI-powered chatbot built for [Systematic IT Solutions](https://systematicitsolutions.com/) to help website visitors explore services, find relevant information, and get quick answers through text and voice conversations.

The assistant supports natural voice interactions, including interruptions, and can navigate the website by scrolling to requested sections and displaying relevant services.

This repository is a **project showcase**. It describes the chatbot and its capabilities; the chatbot's source code is not included.

## Key Features

Text-to-text chat for quick questions about SIS services and information.
Real-time voice-to-voice conversation for natural spoken interaction.
Natural barge-in and interruption — users can speak while the chatbot is responding without waiting for it to finish.
Voice and text website navigation — ask it to find a service, open a section, or scroll directly to the relevant part of the website.
60-second website overview — quickly explains the key services and information available across the SIS website.

## How to Try the Demo

 Open [systematicitsolutions.com](https://systematicitsolutions.com/).
 Open the chatbot on the website.
 Ask a question using text.
 Switch to voice and ask your question naturally.
  While it is speaking, interrupt it and ask another question to test barge-in.
Ask it to find a service or navigate to a specific section, such as “Take me to your services.”.
